ECHO

Meeting audio in: who said what, decisions and action items out, each pointing at the moment it was said. Open models on a CPU, with every name and claim checked against the transcript by code before it's shown.

Code on GitHub Evaluation method
Recorded results, not a live demo. This page replays ECHO's real, unedited output on four meetings it never saw while being built (AMI corpus), next to the human annotations. Running ECHO itself needs a server with about 4 GB of memory, which a static page can't provide; the code runs it locally or in Docker.

      How it works

      Speech to textfaster-whisper small (int8) with a voice filter; every word gets a time.
      Who spoke whenpyannote 3.1: segmentation network, voice embeddings, clustering.
      AlignmentEach word goes to the speaker turn it overlaps most.
      SpeakersQwen2.5-3B proposes names, roles and a quote; code keeps only what the transcript backs up.
      MinutesThe same model reads ~1,800-token sections; each decision must cite a real line.
      QuestionsLangChain BM25 + FAISS retrieval; answers may only cite times actually retrieved.
      Audio and annotations: AMI Meeting Corpus, University of Edinburgh, CC BY 4.0. Models: Whisper (MIT), pyannote (MIT), MiniLM (Apache-2.0), Qwen2.5-3B (Qwen Research License). Built by Janit B.
